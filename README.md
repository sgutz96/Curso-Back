# Curso de Bases de Datos

Curso práctico para comprender el ciclo completo de una base de datos
relacional y su integración con un backend Node.js.

## Ruta de aprendizaje

``` text
01 Fundamentos
      ↓
02 Diseño y modelo E-R
      ↓
03 DDL
      ↓
04 CRUD / DML
      ↓
05 Consultas SQL
      ↓
06 Álgebra relacional
      ↓
07 Varias tablas
      ↓
08 Vistas, índices y seguridad
      ↓
09 Node.js
      ↓
10 Conexión Node.js + MySQL
      ↓
11 API REST con Express
      ↓
12 Proyecto final
```

## Objetivo general

Al finalizar el curso, el estudiante podrá diseñar una base de datos
relacional, crear su estructura mediante SQL, administrar información,
realizar consultas avanzadas y construir una API REST con Node.js y
Express conectada a la base de datos.

## Herramientas

-   MySQL
-   MySQL Workbench
-   Node.js
-   npm
-   Express
-   Postman o Thunder Client
-   Editor de código
-   Git/GitHub

## Convenciones del curso

-   Todas las credenciales deben estar en `.env`.
-   Nunca subir `.env` a GitHub.
-   Utilizar consultas parametrizadas.
-   Probar primero los filtros de `UPDATE` y `DELETE` con `SELECT`.
-   Mantener el modelo normalizado.
-   Documentar decisiones técnicas.
-   Los ejemplos usan principalmente MySQL; otros motores pueden
    requerir ajustes de sintaxis.
